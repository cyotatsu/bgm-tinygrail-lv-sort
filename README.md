# 小圣杯 · 人物/角色按 Lv 排序

Bangumi 小圣杯增强组件：自动将含 **Lv 徽标** 的人物网格 / 角色卡片列表按等级 **从低到高** 排序，并支持一键切换升降序、一键关闭恢复原始顺序。

> ⚠️ **状态说明**
> 本项目**目前尚未在官方「超合金组件库」上架**（暂无审核通过的组件入口）。
> 想使用请按下文「安装方式」**自行复制代码**添加 / 安装；代码完全开源，可放心查看。

---

## 功能特性

- 适配 **新版个人主页「小圣杯-人物」网格** 与 **超展开交易榜角色卡片**；
- 同一容器内 ≥2 个带 Lv 徽标的项自动按 Lv 排序（低 → 高）；
- 页面左下角悬浮控制条：
  - `⇅ 切换`：升序 / 降序切换；
  - `关闭 / 开启`：关闭时恢复页面原始顺序；
- 翻页、切换标签、数据自动刷新后**自动重新排序**；
- 自动跨同源 iframe 生效（超展开右栏等）；
- 仅本地调整展示顺序，**不修改任何游戏数据，无外部请求，无第三方依赖**。

## 安装方式

### 方式一：油猴脚本（Tampermonkey / Violentmonkey）

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)；
2. 打开仓库内 `tinygrail-lv-sort.user.js` 复制全部代码，在油猴中「新建脚本」粘贴保存）；
3. 打开小圣杯页面即可生效，左下角出现控制条。

### 方式二：官方组件平台（自建应用，未上架）

1. 前往 [Bangumi 开发者平台](https://bgm.tv/dev) 创建一个新应用，**类型选择「组件」**；
2. 应用创建后点击「**添加新版本**」：
   - **脚本**：粘贴仓库内 `tinygrail-lv-sort.component.js` 的全部代码；
   - **样式**：留空（样式已内嵌）；
   - **跨域请求**：不勾选（组件无外部请求）；
3. 保存后前往 [个人设置 → 超合金组件](https://bgm.tv/settings/gadgets) 启用；
4. 刷新目标页面即可生效。

## 使用说明

- 排序默认 **Lv 升序（低 → 高）**，同 Lv 保持页面原始顺序；
- 点击左下角 `⇅ 切换` 可切为降序；
- 点击 `关闭` 会停止排序并把列表还原为页面原始顺序（状态会被记住，下次打开保持）；
- 若页面无任何 Lv 徽标列表，脚本不会显示控制条，也不做任何操作。
